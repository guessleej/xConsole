# 與LocModel 2.1.0的功能對齊清單

2026-11-06在HP（Jeff-HPAMDAI，Ryzen AI 9 HX PRO 375／Radeon 880M／32 GB）實機操作LocModel 2.1.0後整理。
使用者要求「全功能補上」，補齊後安裝到HP（Windows單機模式）。本檔是清單真本：每一項做完把狀態改成「完成」並寫上PR。
